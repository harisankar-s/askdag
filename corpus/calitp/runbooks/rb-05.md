## When to use

Use this when the agency.txt parse job failed part-way through a day, so external_gtfs_schedule.agency only has rows for some feeds. Feeds without an agency row have no timezone, and dim_schedule_feeds leaves them out, so the symptom is a dip in feed counts in dim_schedule_feeds and fct_daily_schedule_feeds for one date.

## Steps

1. Find the file that crashed the parse in the job log, and confirm it's malformed (encoding, byte-order mark, broken quoting).
2. Re-run the parse for the date with that file skipped. It will get a failed outcome; the rest will load.
3. Refresh external_gtfs_schedule.agency for the date.
4. Rebuild: `dbt build --select stg_gtfs_schedule__agency+` limited to the affected date, which covers dim_schedule_feeds and fct_daily_schedule_feeds.
5. Tell the agency about the bad file.

## Check

- The feed count in dim_schedule_feeds for the date is within 2% of the days around it.
- fct_daily_schedule_feeds has one row per dataset for the date.
- The bad file shows up as a failed parse outcome, not as missing.
