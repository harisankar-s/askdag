## When to use

Use this when fct_daily_schedule_feeds has more than one row for the same dataset and date. Everything that joins on dataset and date (trip counts, stop counts) will double for those pairs.

## Steps

1. Find the duplicated pairs: group fct_daily_schedule_feeds by dataset key and date and keep groups with more than one row.
2. Look at the two feed versions for a duplicated pair. If their validity windows meet exactly at noon Pacific, the window comparison is the cause; the end of a window must be exclusive.
3. Fix the comparison if needed and rebuild fct_daily_schedule_feeds in full, not just recent dates.
4. Rebuild the daily schedule marts for the affected dates.

## Check

- The uniqueness test on dataset key and date in fct_daily_schedule_feeds passes.
- Daily scheduled trip counts for the affected datasets match the week before.
