## When to use

Use this when airtable.california_transit__organizations is stale or empty: new organizations don't appear in dim_organizations, or organization fields go missing from payments tables such as fct_payments_aggregations. The sync has failed silently before (changed base ID, expired token), so check freshness before assuming the data is right.

## Steps

1. Check when the organizations extract last succeeded and why it stopped.
2. Fix the cause (base ID, token, permissions) and re-run the sync.
3. Rebuild the organizations chain: `dbt build --select stg_transit_database__organizations+`. This rebuilds dim_organizations.
4. If payments tests failed in the meantime, rebuild fct_payments_aggregations and the rides model after dim_organizations, then rerun their tests.
5. Re-run any report that was generated while the data was stale (grant reports especially).

## Check

- dim_organizations has the expected number of current organizations, including any added since the outage.
- The relationships test between rides and fct_payments_aggregations passes.
- No payments aggregation has a null organization name.
