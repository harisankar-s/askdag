## When to use

Use this when airtable.california_transit__services is empty or out of date. Symptoms: bridge_organizations_x_services_managed has no current pairs, service counts drop to zero in inventory reports, or tides_services is missing services that exist in Airtable.

## Steps

1. Check the services sync's last success and its row count.
2. Fix the sync (token, scheduler, Airtable outage) and re-run it for each missing date.
3. Rebuild the services chain: `dbt build --select stg_transit_database__services+`. This covers bridge_organizations_x_services_managed and the services dimension.
4. If the TIDES export is affected, rebuild tides_services and the TIDES vehicle locations, then release the export.
5. Send a correction note for any report that went out with zero services.

## Check

- bridge_organizations_x_services_managed has about the same number of current pairs as last week.
- Every service referenced in TIDES provider records is in tides_services.
- The not-null test on event_timestamp in the TIDES vehicle locations passes.
