## Summary

On 24 July the agency.txt parse job crashed on a file with an invalid encoding, as in March 2025. The skip-and-continue change from then covered malformed rows but not an encoding error raised before any row is read. external_gtfs_schedule.agency had rows only for feeds parsed before the crash, so dim_schedule_feeds and fct_daily_schedule_feeds were missing about a quarter of feeds for the day.

## Impact

- About 25% of feeds were missing from dim_schedule_feeds and fct_daily_schedule_feeds for 24 July.
- Daily schedule marts showed a dip for the date.

## Root cause

A source outage from one bad file, the same failure mode as inc-003 by a different route.

## Fix

Followed rb-05: re-ran the parse with the file skipped, rebuilt dim_schedule_feeds and fct_daily_schedule_feeds for the date. The parser now catches encoding errors per file too.

## Follow-ups

- Add a test file with a bad encoding to the parser's test suite.
